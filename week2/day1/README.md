### Uko Conditional Rendering ikora mu mushinga wanjye
Muri uyu mushinga, nakoresheje **Conditional Rendering** kugira ngo mpe umukoresha amakuru bitewe n'imiterere (state) y'umushinga. 

Uburyo nakoresheje ni:
* **Ternary Operator (? :):** Ibi bituma nerekana ikintu kimwe niba condition ari 'true', naho niba ari 'false' nkwerekana ikindi.
* **Logical AND (&&):** Ibi bikoreshwa iyo nshaka kwerekana ikintu gusa niba condition ari 'true'.
