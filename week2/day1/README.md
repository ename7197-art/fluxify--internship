## Ibisobanuro bya Conditional Rendering
Muri iyi project, nagerageje gukoresha uburyo React ihindura ibyo twereka umukoresha (UI) hashingiwe ku miterere (state) ya application.

### Uburyo nakoze:
1. **Ternary Operator (`? :`):** Nagukoresheje kenshi iyo nshaka guhitamo hagati y'ibintu bibiri (urugero: niba ari *Login* cyangwa *Logout*).
   - *Urugero:* `{isLoggedIn ? <Welcome /> : <Login />}`

2. **Logical AND (`&&`):** Ibi nagiye mbikoresha nshaka kwerekana ikintu gusa niba condition ari impamo (*true*), bitaba ibyo ntihagire ikintu kigaragara.
   - *Urugero:* `{hasNotification && <Alert />}`
